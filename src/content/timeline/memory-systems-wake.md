A node does not wake with noise or spectacle. Lines of light trace long-forgotten
circuitry, and memory tables surface in what had looked like rubble.

What comes back is not the archive. It is fragments: video feeds, code strings,
audio whispers, each tagged with a name and a date, a wall of food-systems data,
a list of children lost to compliance, the melody of a lullaby somebody's mother
hummed.

Reconstruction from that is not restoration. It is a decision, taken repeatedly,
about what to carry forward — which is the only kind of remembering the book
believes in.
